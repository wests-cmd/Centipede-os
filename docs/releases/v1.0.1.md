# Centipede1.0.1 — security and runtime delivery update

The candidate repairs release lint, updates vulnerable build/test dependencies,
and retains explicit local-only demonstration labels. Regular PR validation now
runs the release lint and dependency audit on Linux and Windows.

The live-image build packages the actual compiled Bun web/API service, keeps
root-owned web assets separate from private service-owned state, and retains the
non-root, loopback-only hardened service. Desktop readiness now requires the API
as well as HTML. An isolated real compiled-process smoke checks HTML200,
health200 and locked Files401. Boot-image, Docker and platform gates must still
pass for the exact candidate before publication; the compiled-process check is
not a hardware boot receipt.

Windows Files validates native ACL ownership and write grants rather than Unix
mode bits. Tests cover private directories, Everyone-write rejection, junctions,
traversal, no-overwrite, owner sessions and revocation. Fixture startup polls
readiness with bounded diagnostics, and shell syntax tests use stdin so native
Windows paths are not misinterpreted by a POSIX shell.

Historical1.0.0 download evidence remains historical. This update does not claim
a permanent OS installer, general host administration, universal Kingdom
autonomy or signed phone distribution. Existing signing and authorization gates
remain unchanged. Users must configure their separately deployed Kingdom and
owner secret through the supported private configuration surface.
